# LYLYAS GLOBAL LLC

Corporate website for **Lylyas Global LLC**, a US Wyoming-registered multi-service enterprise delivering strategic clarity, digital capabilities, e-commerce solutions, and international operational support.

- **Official Website**: [https://lylyasglobal.com](https://lylyasglobal.com)
- **Primary Languages**: English (EN), French (FR), Arabic (AR) with RTL support.

## Tech Stack
- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Typography**: Google Fonts (*Amiri*, *Cairo*, *Cormorant Garamond*, *Plus Jakarta Sans*)

## Getting Started

```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## Deployment
Automated GitHub Pages deployment is handled by `.github/workflows/deploy.yml` upon pushing to the `main` branch.
Custom domain `lylyasglobal.com` is configured with Let's Encrypt SSL and apex/www DNS records.
